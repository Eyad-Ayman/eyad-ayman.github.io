Project Manager

Edit your Behance project list, then download the updated file and replace data/behance.json in the repo (or send it back to me to commit). This page can't save to GitHub by itself — GitHub Pages only serves files, it can't write them.

How image files work: each project points at an image already sitting in assets/images/behance/. To add a brand-new project, first drop its exported image into that folder with the filename you type below (e.g. 27-my-new-project.jpg), then fill in the fields here. Reordering, editing, and deleting existing projects needs no image work at all.
